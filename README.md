### Note for Reviewers
This project includes art time. All artwork processes, documentation, and progress tracking can be found in **Nikki Mai Tracking Art for VN.md**. (inside the `art_doc` folder)  
Supporting files such as CSP PSDs and Ibis Paint X speedpaints are also included in the repository for reference.

Robin is a short, wholesome visual novel about the quiet bond between a seamstress and an idol. The story explores themes of comfort and warmth in everyday relationships. You simply click through to progress the dialogue, with hand drawn backgrounds and characters!

Challenges: Working on the art and balancing art time with coding and learning Git version control and markdown formatting for the documentation process.

Thank you for taking the time to play this game!
